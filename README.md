# WIP: My personal skills

## Install

```bash
npx skills@latest add didier/skills
```

Or install one skill at a time:

| Skill | Command |
| --- | --- |
| code-style | `npx skills@latest add didier/skills -s code-style` |
| sketch | `npx skills@latest add didier/skills -s sketch` |
| ste | `npx skills@latest add didier/skills -s ste` |
| writing-style | `npx skills@latest add didier/skills -s writing-style` |
