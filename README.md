# WIP: My personal skills

## Install

```bash
npx skills@latest add didier/skills
```

Or install one skill at a time:

| Skill | Description | Command |
| --- | --- | --- |
| code-style | An opinionated good default for code style. | `npx skills@latest add didier/skills -s code-style` |
| sketch | Bring a paper sketch or diagram into the chat by photographing it with the user’s iPhone, so they can draw an idea by hand instead of describing it in words. | `npx skills@latest add didier/skills -s sketch` |
| ste | Write ASD-STE100 Simplified Technical English. | `npx skills@latest add didier/skills -s ste` |
| writing-style (WIP) | Opinionated prose defaults for essays, docs, PR descriptions, commit messages, review comments, and UI copy. | `npx skills@latest add didier/skills -s writing-style` |
